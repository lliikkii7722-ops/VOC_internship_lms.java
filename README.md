# Library Management System (LMS)

## Overview
This is a **Java console-based Library Management System** developed during an internship.  
The system allows a library to **add books, issue and return them, and view all book details**.  
It demonstrates **Object-Oriented Programming (OOP)** concepts, use of **ArrayList**, **loops**, **conditional statements**, and **Java’s `LocalDate`** for tracking issue dates.

---

## Features
1. **Add Books**
   - Enter book ID and name
   - Book is stored in the library system
   - Displays confirmation and book details immediately

2. **Issue Books**
   - Issue a book by ID
   - Automatically records the **current date** of issue
   - Shows success message and issued book details
   - Prevents issuing an already issued book

3. **Return Books**
   - Return a book by ID
   - Shows when it was issued
   - Updates the book status to available

4. **View Books**
   - Displays all books in a **professional table format**
   - Shows **ID, Name, Issued status, Issue Date**

5. **Exit**
   - Exit the application safely
